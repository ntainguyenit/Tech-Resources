# Cổng Thông Tin Tài Nguyên Công Nghệ — Kho Lưu Trữ Học Thuật Được Tuyển Chọn

Một kho lưu trữ kỹ thuật số được tuyển chọn chuyên nghiệp và có độ tin cậy cao, được thiết kế dành cho các kỹ sư phần mềm, nhà nghiên cứu và sinh viên khoa học máy tính. Dự án này nhằm mục đích tập trung các tài nguyên kỹ thuật cốt lõi trong khi vẫn duy trì các tiêu chuẩn chất lượng học thuật nghiêm ngặt.

---

## Triết lý Dự án

**Cổng Thông Tin Tài Nguyên Công Nghệ** hoạt động theo nguyên tắc **"Chất lượng hơn Số lượng."** Trong thời đại tràn ngập thông tin, nền tảng này đóng vai trò như một bộ lọc ngữ nghĩa để chỉ cung cấp cho người dùng những công cụ mạnh mẽ và đã được xác minh nhất cho hành trình phát triển của họ.

### Các Mục tiêu Chính:
- **Tuyển chọn**: Lựa chọn có hệ thống các thư viện, khung phát triển (framework) và tài liệu giáo dục.
- **Khả năng tiếp cận**: Hỗ trợ đa ngôn ngữ (Tiếng Anh/Tiếng Việt) để tiếp cận toàn cầu và địa phương.
- **Hiệu năng**: Giao diện người dùng tốc độ cao, phản hồi nhanh và tối giản.

---

## Kiến trúc Hệ thống

| Tầng | Công nghệ | Mục đích |
| :--- | :--- | :--- |
| **Nhân Frontend** | React 19 + TypeScript | Logic an toàn kiểu dữ liệu và hướng thành phần. |
| **Định dạng giao diện** | Vanilla CSS (CSS Variables) | Hệ thống thiết kế hiệu năng cao, ít hao phí tài nguyên. |
| **Quản lý Trạng thái** | React Context API | Quản lý Giao diện (Theme) và Bản địa hóa (Locale). |
| **Công cụ đóng gói** | Vite 8 | Phát triển cực nhanh và tối ưu hóa bản dựng sản xuất. |
| **Hiệu ứng** | Framer Motion | Hiệu ứng vi mô tinh tế để nâng cao trải nghiệm người dùng (UX). |

---

## Các Tính năng Cốt lõi

- **Điều hướng Chế độ Tối**: Được tối ưu hóa cho môi trường nghiên cứu trong điều kiện ánh sáng yếu.
- **Giao diện Song ngữ**: Chuyển đổi liền mạch giữa tiếng Anh và tiếng Việt.
- **Tìm kiếm Thời gian thực**: Lọc siêu dữ liệu tài nguyên với hiệu năng cao.
- **Thanh bên Danh mục Cố định**: Tiếp cận liên tục các danh mục tài nguyên để điều hướng nhanh chóng.

---


## Phương pháp Phân loại Tài nguyên

Mỗi mục nhập trong tập dữ liệu `resources.ts` đều trải qua quá trình đánh giá dựa trên:
1. **Tiện ích**: Nó có giải quyết một vấn đề kỹ thuật cụ thể không?
2. **Tuổi thọ**: Tài nguyên có được bảo trì tốt và có khả năng tồn tại lâu dài không?
3. **Độ phức tạp**: Nó có cung cấp chiều sâu phù hợp cho cả người mới bắt đầu và lập trình viên lâu năm không?

# Tech Resources Hub — Academic Curated Repository

A professionally curated, high-integrity digital repository designed for software engineers, researchers, and computer science students. This project aims to centralize essential technical resources while maintaining strict academic quality standards.

---

## Project Philosophy

The **Tech Resources Hub** operates under the principle of **"Quality over Quantity."** In an era of informational overflow, this platform serves as a semantic filter to provide users with only the most robust and verified tools for their developmental journey.

### Key Objectives:
- **Curation**: Systematic selection of libraries, frameworks, and educational materials.
- **Accessibility**: Multi-language support (EN/VI) for global and local reach.
- **Performance**: High-speed, responsive, and minimalist user interface.

---

## System Architecture

| Layer | Technology | Purpose |
| :--- | :--- | :--- |
| **Frontend Core** | React 19 + TypeScript | Type-safe, component-driven logic. |
| **Styling** | Vanilla CSS (CSS Variables) | High-performance, low-overhead design system. |
| **State Management** | React Context API | Theme and Locale management. |
| **Build Tool** | Vite 8 | Ultra-fast development and optimized production bundles. |
| **Animation** | Framer Motion | Subtle micro-animations for enhanced UX. |

---

## Core Features

- **Dark Mode Navigation**: Optimized for low-light research environments.
- **Bi-lingual Interface**: Seamless transition between English and Vietnamese.
- **Real-time Search**: High-performance filtering of resource metadata.
- **Sticky Taxonomy Sidebar**: Constant access to resource categories for rapid navigation.

---


## Resource Classification Methodology

Every entry in the `resources.ts` dataset undergoes an evaluation based on:
1. **Utility**: Does it solve a specific technical problem?
2. **Longevity**: Is the resource well-maintained and likely to persist?
3. **Complexity**: Does it provide depth suitable for both beginners and seniors?
